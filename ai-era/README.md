# ai-era

A website where I capture the topics I want to publish on around AI:

- **AI ethics**
- **AI's potential to transform the world**

One static page, `index.html`: no build step, no dependencies, and no call to
a third party (no web fonts, CDN, analytics or embeds). Served by GitHub Pages
at <https://nklassen-app.github.io/kairos-public-profile/ai-era/>. Adding or
rewording a topic is an edit to `index.html` and a push.
